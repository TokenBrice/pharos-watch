# Pharos Roadmap

This roadmap is intentionally directional. Methodology and data-pipeline changes still require sourced implementation details, tests, and matching docs before they ship.

## Current Priorities

- Improve stablecoin metadata and source coverage without weakening data-admission rules.
- Expand transparent reserve, redemption, liquidity, and issuer-control coverage where primary sources are reliable.
- Keep the public API useful for integrators through stable contracts, OpenAPI/Postman artifacts, and clear examples.
- Preserve data reliability: freshness metadata, status surfaces, circuit breakers, and documented degraded modes.
- Improve onboarding for outside contributors through issue templates, contributor docs, and smaller well-labeled tasks.

## Good First Public Contributions

[CONTRIBUTING.md](./CONTRIBUTING.md) owns the contribution lanes and the review expectations for each one.

## Changelog

User-facing changes are published on [pharos.watch/changelog](https://pharos.watch/changelog/) and methodology changes are tracked from [pharos.watch/methodology](https://pharos.watch/methodology/). GitHub Releases are reserved for repository-level public milestones.
