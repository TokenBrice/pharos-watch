# Table Exports

## Export Contract

Interactive table exports prepend provenance in CSV, NDJSON, and Markdown. Producer metadata dates `asOfISO` and participating upstream generations, never browser receipt or download time. `TableExportMenu` forwards an optional nullable `sourceGenerations` map to every format without changing callers that do not provide it.

The Screener is a **mixed-source export**, not an atomic snapshot: stablecoin supply, peg summary, report cards (including mint control), stress signals and liquidity each contribute columns. The stablecoin directory table is also mixed-source over its four feeds (stablecoins, peg summary, report cards, liquidity). The Screener uses the conservative scalar As-of convention: the **oldest participating producer generation, only when all participating clocks are known**. Otherwise its `asOfISO` is `unknown`; every participating source stays listed, each missing clock remains null in NDJSON's `sourceGenerations` and reads `unknown` in CSV/Markdown. Each clock comes from that source's `meta.updatedAt`, so refetching cached data does not renew its generation. The stablecoin directory table instead dates its CSV by the oldest **known** generation (null/unread clocks never withhold the clocks that were read), falling back to `unknown` only when none is known; it always emits all four source keys, null when that source was not read. When its report-card response is loaded, the directory CSV methodology label appends that response's Safety Score version (`published source values · safety-score v10.01`); absent that response the label stays `published source values`.

Export cells preserve missing data instead of inventing values. In particular, a Screener row without a published supply exports an empty `supply_usd` cell, while an explicitly observed zero supply exports `0`. Yield leaderboard safety provenance is exported exactly as published: `live-report-card`, `cached-publish`, `default-safety`, `opportunity-safety`, or `safety-snapshot-unavailable`; an absent value exports as `unknown`. A yield row whose live safety card is a `pipeline-gap` (null grade and score) exports `unknown` in both safety cells, never `NR`; `NR` is only the published not-rated grade.

Yield leaderboard and comparison CSVs select a shared row projection in `src/lib/yield-presentation.ts`; each keeps its existing column order and source header, and the leaderboard adds rank. Both preserve the same NR, unknown-value, qualification, and safety-provenance cells. The yield leaderboard preamble keeps `As of` as the yield publication generation and adds an optional `Source assessed: <ISO>` field from the response assessment clock (`sourceClock.assessedAt`), which is the reference clock for the exported `Source age seconds` column; the field is omitted when that clock is unknown.
