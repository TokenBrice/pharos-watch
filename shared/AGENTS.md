# Shared Agent Notes

Applies to `shared/`; `shared/data/stablecoins/AGENTS.md` is the more specific stablecoin context.

## Read First

- `docs/architecture.md` § “File Tree Guide” and § “TypeScript Target Constraints”.
- `docs/classification.md` for stablecoin or taxonomy work; `docs/methodology-page.md` for scoring work.

Route with `node --import tsx scripts/ci/pharos-change-contract.ts --file <path>`.

## Rules and owners

- `shared/lib/` is runtime-neutral, compiles under root and Worker targets, and must not import frontend or Worker-only modules.
- Per `eslint.config.mjs`, production files in `shared/lib/` must use relative imports instead of `@shared/*` aliases.
- `shared/data/safety-score-v9/evaluation-build-manifest-v1.ts` is generated by `npm run generate:safety-score-v9-evaluation-build`; `shared/data/safety-score-v9/methodology-policy-candidate-v1.json` is curated policy.
- `shared/lib/methodology-versions/` owns version exports and registry wiring; structured changelogs live in `shared/data/methodology-changelogs/`. Follow ADR-3 in `docs/architecture.md`.
- `shared/lib/cron-jobs.ts` and `shared/lib/scheduled-runner-registry.ts` are schedule authority; see `docs/process/cron-trigger-policy.md` § “Source Of Truth”.
- Keep `shared/types/status.ts` as the compatibility barrel described by `docs/architecture.md` § “File Tree Guide”.

## Wire contracts

- Own each cross-runtime wire shape and vocabulary once in `shared/types/`; derive TypeScript types from its schema (`z.output<typeof Schema>`) rather than maintaining parallel interfaces or literal unions in consumers. Worker and frontend readers import that authority.
- Reuse primitive authorities: `shared/types/safety-schema-primitives.ts`, `shared/lib/evm-address.ts`, and `shared/lib/stablecoin-id.ts`. Compose existing schemas instead of retyping their validation.
- Derive registry-backed lists from the registry; a necessary explicit mapping must have a registry-iterating completeness test (ADR-32).
- At absence-sensitive supply boundaries use `getCirculatingRawOrNull()` and historical `*OrNull` helpers. Zero-default helpers are deleted and banned by ESLint; absent, empty, or invalid buckets are not observed zero.

## Common Checks

- `npm run lint` for import boundaries; `npm run check:stablecoin-data` when stablecoin metadata changes.
- Run focused suites under `shared/lib/__tests__/` for touched logic.
