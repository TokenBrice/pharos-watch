# Q-214 — Function named `tradingShareStaleExceeded` while the check is named `tradingStaleExceeded` at the call site
**Low** · effort **S** · _naming_ · pillar **quality**
**Location:** `src/app/screener/picker/client.tsx:L167, L430`
**Found by slice:** `sa-routes-4`
## Problem
The helper function is declared as `tradingShareStaleExceeded` (L430) but the local variable it is assigned to is named `tradingStaleExceeded` (L167). The word 'share' in the function name is semantically confusing — it does not check market share but rather whether trading-mode data staleness thresholds are exceeded. The mismatch makes a grep for either name incomplete.
## Proposed remediation
Rename the function to `isTradingDataStale` or `tradingDataStaleExceeded` and update the local variable accordingly.
