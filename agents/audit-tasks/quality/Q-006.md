# Q-006 — Dead null-coalescence in yield-source risk scoring (sourceRiskInverted always returns number)
**Medium** · effort **S** · _dead-code_ · pillar **quality**
**Location:** `shared/lib/selector/yield-source.ts:L70-L71`
**Found by slice:** `sh-selector`
## Problem
yieldSourceScore computes risk as: sourceRiskInverted(candidate.sourceRiskScore) ?? riskTierScore(candidate.venueRiskTier). sourceRiskInverted has return type number (never null — it returns 50 for null input). The ?? branch is unreachable dead code that silently misleads readers into thinking the function can return null and that riskTierScore is a genuine fallback. If sourceRiskScore is null, the result is always 50, not riskTierScore — the fallback never fires.
## Proposed remediation
Remove the ?? riskTierScore(...) branch. If a tier-based fallback is intentionally preferred when sourceRiskScore is null, change sourceRiskInverted to return null for null input and add explicit null-handling here.
