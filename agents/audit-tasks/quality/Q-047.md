# Q-047 — Unvalidated `as SelectorOutput` cast on snapshot network response
**Medium** · effort **M** · _type-safety_ · pillar **quality**
**Location:** `src/app/screener/picker/use-selector.ts:L54`
**Found by slice:** `sa-routes-2`
## Problem
`(await response.json()) as SelectorOutput` at line 54 casts the raw network payload to the internal `SelectorOutput` type without any runtime validation. If the stored snapshot shape changes (methodology version bumps, added/removed fields), the cast silently succeeds and callers receive a structurally incorrect object. This can surface as silent wrong data or a runtime crash when consuming code accesses missing nested fields.
## Proposed remediation
Add a lightweight structural validation (e.g. check that `output.rows` is an array and `output.input` is present) before accepting the cast, and return `{ kind: 'error', reason: 'snapshot-corrupt' }` on mismatch. A full Zod parse is ideal but even a duck-type guard on the top-level shape catches obvious breakage.
