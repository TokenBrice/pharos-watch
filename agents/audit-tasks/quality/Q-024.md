# Q-024 — buildResultSummaryCoordinationProps erases all prop types via Record<string, unknown>
**Medium** · effort **S** · _type-safety_ · pillar **quality**
**Location:** `src/app/screener/picker/handoff.ts:L128`
**Found by slice:** `sa-routes-4`
## Problem
The function returns `Record<string, unknown>` and is spread directly into a JSX component (`{...buildResultSummaryCoordinationProps(...)}`). This bypasses TypeScript's prop checking for SelectorResultSummary entirely: misspelled prop names, wrong value types, and unused keys (see the dead `screenerFilterChips` finding above) all pass silently. Any future refactor of SelectorResultSummary's props will not cause a compile error here.
## Proposed remediation
Replace `Record<string, unknown>` with a concrete `Pick<SelectorResultSummaryProps, 'answerChips' | 'priorityLabels' | 'filterChips' | 'usedRelaxedFallback' | 'relaxedReasons'>` type. Import the interface from the component or a shared types file.
