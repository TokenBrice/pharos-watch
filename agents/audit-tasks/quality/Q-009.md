# Q-009 — serve-static-export.mjs introduces a redundant alias that adds a full module-level promise just to avoid repeating the variable name
**Medium** · effort **S** · _complexity_ · pillar **quality**
**Location:** `scripts/maintenance/serve-static-export.mjs:L119-L128, L265`
**Found by slice:** `scripts-maint-3`
## Problem
getSiteDataResolver() (L119-L128) is a module-scope promise cache for a dynamic import. Inside the request handler at L265, the result is immediately stored as const isSiteDataRequest = isSiteDataPath — a pure rename of a variable that already exists in the same scope. All five subsequent usages of isSiteDataRequest could use isSiteDataPath directly with no change in semantics. The alias adds cognitive load and is a likely artifact of a refactor that was not fully completed.
## Proposed remediation
Delete line 265 (const isSiteDataRequest = isSiteDataPath) and replace all references to isSiteDataRequest in the block with isSiteDataPath.
