# Q-033 — normalizeDependencyMeta in homepage-bootstrap-runtime.ts uses as never cast to work around type mismatch
**Medium** · effort **S** · _type-safety_ · pillar **quality**
**Location:** `src/lib/homepage-bootstrap-runtime.ts:51-75`
**Found by slice:** `sl-core-3`
## Problem
The function `normalizeDependencyMeta` (L51) declares its return type as `ApiMeta['dependencies'] extends infer D ? D : never` — a conditional type used purely to avoid importing the concrete `ApiDependencyMeta` type from `@shared/types/api-meta`. The internal `normalized` object is explicitly cast `as never` at L74 to silence a type error. This is a type-safety escape hatch: the compiler cannot verify the shape matches, and a future change to `ApiDependencyMeta` (e.g., adding a required field) would be silently missed here.
## Proposed remediation
Import `ApiDependencyMeta` directly from `@shared/types/api-meta` and declare the return type concretely. This is resolved automatically if the deduplication finding (normalizeApiMeta clone) is addressed first.
