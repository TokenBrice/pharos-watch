# R-004 — parseSitemapLocs duplicated across check-seo-static.mjs and check-seo-live-smoke.mjs
**Medium** · effort **S** · _clone_ · pillar **redundancy**
**Location:** `scripts/ci/check-seo-static.mjs:L547-L558, scripts/ci/check-seo-live-smoke.mjs:L53-L63`
**Found by slice:** `sc-ci-1`
## Problem
Both files contain an identical XML-parsing function (same regex, same accumulation loop) that extracts <loc> values from a sitemap. The only difference is the return type: check-seo-static.mjs returns a Set (for has() membership checks) and check-seo-live-smoke.mjs returns an Array (for slice/iteration). The regex body is character-for-character identical. No shared scripts/lib helper exists.
## Proposed remediation
Extract a shared parseSitemapLocs(xml, { asSet? }) helper into scripts/lib/seo-static-helpers.mjs (or similar) and import it in both consumers. The caller determines which return type it needs, or the helper accepts an option.
