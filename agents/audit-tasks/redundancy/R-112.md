# R-112 — telegram-digest-appendices.ts rebuilds TRACKED_META_BY_ID instead of importing it
**Low** · effort **S** · _clone_ · pillar **redundancy**
**Location:** `worker/src/lib/telegram-digest-appendices.ts:L36`
**Found by slice:** `wl-core-1`
## Problem
const TRACKED_META_BY_ID = new Map(TRACKED_STABLECOINS.map((coin) => [coin.id, coin])) at line 36 is a local shadow. The identical map is already exported as TRACKED_META_BY_ID from @shared/lib/stablecoins/registry, which the file already uses (TRACKED_STABLECOINS, FROZEN_IDS, FROZEN_META_BY_ID are all imported from that registry). This means the file builds a second in-memory Map over the same 400+ entry list on every cold start, and any future change to the registry type will need to be tracked in two places.
## Proposed remediation
Remove the local declaration and add TRACKED_META_BY_ID to the import from @shared/lib/stablecoins/registry.
