# R-065 — Three independent directory-walk implementations when source-files.mjs already exists
**Medium** · effort **S** · _clone_ · pillar **redundancy**
**Location:** `scripts/lib/hotspot-ratchet.mjs:L80-L105, scripts/lib/critical-coverage.mjs:L329-L352, scripts/lib/source-files.mjs:L10-L39`
**Found by slice:** `scripts-lib`
## Problem
source-files.mjs exports `collectSourceFiles` with configurable extensions and excluded-dirs filtering, yet both hotspot-ratchet.mjs and critical-coverage.mjs implement their own private `walk()` loops (same `readdirSync(..., {withFileTypes: true})` + dot-file skip + isDirectory recursion pattern). The only real differences are the post-walk predicate (`shouldSkipHotspotScanFile` / `shouldSkipCriticalCoverageScanFile`) and extension filtering — nothing that prevents using the shared helper.
## Proposed remediation
Replace the private walk loops in hotspot-ratchet.mjs and critical-coverage.mjs with `collectSourceFiles` / `collectSourceFilesUnderRoot` from source-files.mjs, passing the scan roots, extension sets, and excluded-dir sets as options; then apply the domain-specific predicate as a post-filter on the result.
