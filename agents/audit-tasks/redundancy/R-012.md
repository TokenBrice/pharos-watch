# R-012 — stringValue() defined six times across scripts with identical body
**Medium** · effort **S** · _clone_ · pillar **redundancy**
**Location:** `scripts/maintenance/audit-dex-pricing-source-gaps.ts:L151-L153, scripts/maintenance/generate-dependency-coverage-audit.ts:L159-L161, scripts/maintenance/generate-reserve-coverage-audit.ts:L336, scripts/maintenance/audit-price-source-depth.ts:L212, scripts/maintenance/audit-dia-provider-poc.ts:L108, scripts/maintenance/generate-l2beat-snapshot-coverage-audit.ts:L130`
**Found by slice:** `scripts-maint-2`
## Problem
All six files define the same two-line function `function stringValue(value: unknown): string | null { return typeof value === 'string' && value.trim().length > 0 ? value.trim() : null; }`. The sibling `numberValue()` is already exported from `scripts/lib/coverage-audit-cli.ts` (L16), but `stringValue` was never added to that shared module. Several files already import from that module (e.g., audit-dex-pricing-source-gaps.ts:L7 imports `isRecord` from it), making the duplication purely accidental.
## Proposed remediation
Export `stringValue` from `scripts/lib/coverage-audit-cli.ts` alongside `numberValue` and replace all six local definitions with an import. One grep-and-replace; no behavior change.
