# R-159 — getCoinsByLifecycleStatus accepts a 'dead' status that is unreachable and always returns []
**Low** · effort **S** · _dead-code_ · pillar **redundancy**
**Location:** `shared/lib/stablecoins/by-mechanism.ts:L74-L91`
**Found by slice:** `sh-class`
## Problem
The function signature accepts `status: 'active' | 'pre-launch' | 'frozen' | 'dead'` but the implementation handles 'dead' only with `return []` (the else branch). 'dead' is not in the `StablecoinStatus` type (`STABLECOIN_STATUS_VALUES` = ['pre-launch', 'active', 'frozen']). No production caller passes 'dead'; the only occurrence is a single test asserting the empty-array return. The branch widens the public API with a non-existent lifecycle concept.
## Proposed remediation
Remove 'dead' from the parameter union. Update the test to verify that TypeScript rejects the value, or simply delete that test case. The else branch becomes dead code and can be removed.
