# R-211 — api-key-format.ts is a three-line file that wraps a one-line Date call
**Low** · effort **S** · _wrapper_ · pillar **redundancy**
**Location:** `src/lib/api-key-format.ts:1-3`
**Found by slice:** `sl-core-2`
## Problem
The entire file exports a single function: `return new Date(epochSeconds * 1000).toLocaleString()`. It has exactly three consumers (api-key-admin-view-model.ts, api-key-request-form-view-model.ts, api-key-request-admin-view-model.ts). This is a no-value abstraction — the wrapper carries no validation, no format options, and no additional logic; callers could inline the expression or use the shared date formatters directly.
## Proposed remediation
Inline `new Date(expiresAt * 1000).toLocaleString()` at the three call sites and delete api-key-format.ts. Alternatively, if a locale-aware format with explicit options is desired, promote to a proper utility in shared/lib/format.ts.
