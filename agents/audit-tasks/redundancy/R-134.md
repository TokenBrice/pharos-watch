# R-134 — mint-burn-spike and blacklist-surge annotation kinds are declared but never reachable on charts
**Low** · effort **S** · _dead-code_ · pillar **redundancy**
**Location:** `shared/types/chart-annotation.ts:L12-19, src/hooks/use-chart-annotations.ts:L66-78, src/components/chart-primitives/annotations.tsx:L14-19`
**Found by slice:** `data-annotations`
## Problem
Two ChartAnnotationKind values — 'mint-burn-spike' and 'blacklist-surge' — are in the enum, registered in ANNOTATION_HEX_COLORS, and validated by the test suite. However, they are never used in curated-annotations.ts (zero occurrences), and mapWorkerKind() in use-chart-annotations.ts explicitly does not map any tape event type to them (only 'depeg.opened' and 'methodology.*' reach the chart). The kinds carry dead weight: they occupy color-table slots and add test burden with zero rendering path.
## Proposed remediation
If these kinds are intentionally reserved for future tape-to-chart mapping, add a code comment in mapWorkerKind() documenting the planned types. If there is no concrete plan, remove them from CHART_ANNOTATION_KINDS, ANNOTATION_HEX_COLORS, and the test enum check to keep the type lean.
