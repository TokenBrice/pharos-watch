# R-003 — formatRatio duplicated across two status files
**Medium** · effort **S** · _clone_ · pillar **redundancy**
**Location:** `worker/src/lib/status/evaluation-causes.ts:L17-L19, worker/src/lib/status/onchain-data-quality.ts:L7-L9`
**Found by slice:** `wl-status`
## Problem
The function `formatRatio(value: number): string` is defined identically (same body: `${(value * 100).toFixed(2)}%`) in both files. Any change to the format (e.g., adding a locale separator) must be made twice and is easy to miss.
## Proposed remediation
Extract `formatRatio` to a shared utility within the `status/` sub-folder (e.g., `status/format.ts`) and import it in both files.
