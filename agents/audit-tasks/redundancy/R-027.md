# R-027 — Exact clone of canListen/allocatePort/resolveStaticExportPort across two scripts
**Medium** · effort **S** · _clone_ · pillar **redundancy**
**Location:** `scripts/maintenance/lighthouse-static-export.mjs:114-152, scripts/maintenance/run-pages-smoke.mjs:52-93`
**Found by slice:** `scripts-maint-1`
## Problem
canListen() (12 lines) and allocatePort() (16 lines) are character-for-character identical in both files. resolveStaticExportPort() diverges in return type (number in lighthouse, string in pages-smoke) — a latent inconsistency introduced by the copy. scripts/lib/smoke-runtime.mjs exists as a shared utility module for this slice but does not contain these helpers.
## Proposed remediation
Extract canListen and allocatePort into scripts/lib/smoke-runtime.mjs (or a new scripts/lib/port-utils.mjs). Fix resolveStaticExportPort in both callers to agree on a single return type (number). The pages-smoke version currently passes a string port to canListen which expects a number — this works at runtime via coercion but is a readability hazard.
