  - The repo intro now clarifies `166 tracked = 158 active + 8 pre-launch`, which matches [shared/lib/stablecoins/index.ts](/home/ahirice/Documents/git/stablecoin-dashboard/shared/lib/stablecoins/index.ts).
- Coverage doc drift:
  - The public matrix is now 9 features, not 8. `redemption` is a first-class feature in [src/lib/coverage.ts](/home/ahirice/Documents/git/stablecoin-dashboard/src/lib/coverage.ts).
  - The live column label is `Live Reserves Sync`, not just `Reserves`.
  - The route model pulls redemption coverage from [src/hooks/use-coverage-matrix-model.ts](/home/ahirice/Documents/git/stablecoin-dashboard/src/hooks/use-coverage-matrix-model.ts) via `useRedemptionBackstops()`.
  - The stale banner also reflects the redemption-backstops query from the same hook model.
- Architecture / worker infrastructure drift:
  - Both docs overstated SQL migration count by one.
