# CORE DIRECTIVE

**All artifact documents produced by agents must be placed in this /agents/ folder, according to the structure described below:**

Each document must be prefixed with the date of its creation, ex `2026-06-03-full-codebase-audit.md`

## `/audits`

Any audits produced by agents is placed in this folder

## `/plans/`

For design and implementation plans. Once a plan has been implemented, it must be moved to `/plans/historical/`

## `/research/`

For research reports that are not audits

## `/tasks/`

For pending tasks tracking. Completed tasks document are move to `/tasks/done/`

### `/process/`

For recurring and standardized processes

### `/retrospectives/`

Used during cmcs implementation only, to place the restropective regarding the cmcs workflow performance.
